# 🤖 Rule-Based Chatbot

A simple web-based rule-based chatbot built using Python, Flask, HTML, CSS, and JavaScript.

## 📌 Project Overview

This chatbot uses predefined rules and keywords to understand user messages and provide appropriate responses.

It is designed as a beginner-friendly chatbot without using machine learning or external AI APIs.

## 🚀 Features

- Rule-based response system
- Keyword-based message matching
- Interactive web interface
- Flask backend
- HTML/CSS frontend
- JavaScript for communication with the backend
- Easy to add new chatbot rules

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
